## 一、数据流全链路

```
摄像头 (MT9V03X 188×120)
  ↓ compressimage() → 100×60
  ↓ turn_to_bin() → 二值化
  ↓ median_filter() + image_filter()
  ↓
track_find_line()
  ├─ basic_line_tracking()      → 逐行扫描边界 → center_line[60]
  ├─ detect_element_features()  → 边缘特征 → top/inner/outer/offset
  ├─ identify_element_and_supplement() → 元素分类 + 中线补线
  └─ update_align_state()       → 弯道进出/回正状态
  ↓
track_get_error()
  ├─ track_error  (加权偏差, 供位置PID)
  └─ track_angle  (中线斜率, 供角度PID)
  ↓
adjust_steering_pid()  → 根据元素类型切换 Kp/Kd
pid_calculate()        → 位置环 + 角度环 → total_steer
get_target_speed()     → 根据元素类型 + 元器件 + 前瞻 → target_speed
  ↓
差速公式: l_duty=target+speed_output-total_steer, r_duty=target+speed_output+total_steer
  ↓
my_motor_set_speed() → PWM输出 → 电机
```

## 二、元素检测决策树

```
摄像头图像 → detect_element_features()
  ├─ top_found:    顶部15行横向扫线, 找黑白跳变 (≥2次)
  ├─ inner_found:  最边缘12列纵向扫线, 找黑→白跳变 (>2列命中=直角弯特征)
  ├─ outer_found:  最边缘25列纵向扫线, 找黑→白跳变 (钝角弯特征)
  └─ center_offset: 底部5行center_line均值 - 图像中心

identify_element_and_supplement() 决策:
  ┌──────────────────────────────────────────────────────────┐
  │ 1. inner_r=1, inner_l=0, top=0 → 右直角弯               │
  │ 2. inner_r=0, inner_l=1, top=0 → 左直角弯               │
  │ 3. inner_r=1, inner_l=0, top=1 → T形路口(右支路)         │
  │ 4. inner_r=0, inner_l=1, top=1 → T形路口(左支路)         │
  │ 5. inner_r=1, inner_l=1, top=1 → 十字路口               │
  │ 6. inner_r=0, inner_l=0, top=1 → 直道                    │
  │ 7. all=0, |offset|>20        → 直角弯(内区漏检兜底)      │
  │ 8. all=0, |offset|>8         → 钝角弯                    │
  │ 9. all=0, |offset|≤8         → 断路                      │
  │ 10. 其余组合                  → 钝角弯(兜底)              │
  └──────────────────────────────────────────────────────────┘
  ↓ (T→R防抖: 上帧T+本帧同侧R → 覆写为T, 8帧维持期)
```

## 三、直角弯数值追踪

> 场景: 物理右转 → TFT180图像翻转 → 赛道在图像左侧

```
假设 center_line: 底部6行≈10(左边缘), 上部≈3-5

track_get_error (15行, rows 45-59, 加权平均):
  error_sum ≈ -5025, weight_sum = 120
  track_error = -5025/120 ≈ -42

PID计算 (Kp=12, Kd=14):
  p_term = 12 × (-42) = -504
  d_term = 14 × (-42 - (-20)) = -308    (假设上帧error=-20)
  steer_output = -812

差速输出:
  l_duty = 600 + 0 - (-812) = 1412
  r_duty = 600 + 0 + (-812) = -212 → clamp to DUTY_MIN=500
  左右差 = 1412 - 500 = 912 → 强力右转 ✅
```

## 四、直线数值追踪

```
假设 center_line: ≈50±3 (轻微波动)

track_get_error (10行, rows 50-59):
  track_error ≈ ±3

PID计算 (Kp=5, Kd=11):
  p_term = 5 × 3 = 15
  d_term = 11 × (3-2) = 11
  steer_output ≈ 26

差速输出:
  l_duty = 750 - 26 = 724
  r_duty = 750 + 26 = 776
  左右差 = 52 → 微小修正 ✅
```

## 六、符号约定

```
TFT180_CROSSWISE_180 旋转 → 图像左右翻转
  物理右侧 → 图像左侧
  物理右转 → 图像左边缘 → center_line≈10 → track_error<0 → 负steer → 右转

差速公式:
  l_duty = target + speed - total_steer
  r_duty = target + speed + total_steer
  total_steer < 0 → r_duty < l_duty → 右转 ✅
  total_steer > 0 → r_duty > l_duty → 左转 ✅
```

## 七、关键保护机制

| 机制 | 位置 | 作用 |
|------|------|------|
| 帧间记忆 | basic_line_tracking | 上帧底部中线→本帧搜索起点 |

| 转弯5帧防抖 | junction_execute_turn | 元素类型抖动不提前退出 |
| 元器件10帧衰减 | cpu0_main.c | 通过后恢复正常速度 |
| lose_line_count重置 | basic_line_tracking | 宽度异常不累积丢线 |
