## ⚠️ PID 调参核心原则（每次调参前必读）

### 1. 输入必须可靠
`track_error` 是 PID 的眼睛。摄像头看不到线（丢线、误判），再好的参数也没用。**先确认车在赛道上能看到线。**

### 2. 一次只调一个参数
改 Kp 就别动 Kd。调完一个参数跑一圈看效果，再调下一个。**同时改两个永远不知道谁起了作用。**

### 3. 固定速度再调参数
速度变了，同一组 PID 参数效果完全不同。**先锁死 BASE_SPEED，调完转向再考虑提速。**

| 参数 | 调法 | 过头了的表现 |
|------|------|------------|
| Kp ↑ | 慢慢加，直到能跟上弯道 | 直道画龙、左右振荡 |
| Kd ↑ | 慢慢加，直到振荡消失 | 转向迟钝、弯道拐不过来 |

### 4. 从小往大调 Kp，从大往小调 Kd

| 看 ch0 (偏差) | 判断 |
|--------------|------|
| 直道接近 0，小幅波动 | ✅ 正常 |
| 直道来回正负跳动 | Kp 太大或 Kd 太小 |

| 看 ch4 (转向输出) | 判断 |
|------------------|------|
| 频繁撞到 ±1600 极限 | Kp 不够，或弯道太急 |
| 始终在 ±500 以内 | Kp 够了，可以试试提速 |

### 5. 示波器是唯一的真相
波形不会骗人。手感、猜测、经验都不可靠。**手持调参的参数放地上跑一定翻车。**

## 一、PID控制器系统概述

### 1.1 三环控制系统结构

```
┌─────────────────────────────────────────────────────────┐
│                 巡线小车三环控制系统                    │
├─────────────────────────────────────────────────────────┤
│                                                         │
│  图像处理 → track_error (横向偏差)                      │
│                    │                                   │
│                    ▼                                   │
│         ┌─────────────────────┐                       │
│         │ 转向环 (PD)          │ ← 控制转向电机角度     │
│         │ Kp=5, Kd=11, Ki=0   │                       │
│         └─────────────────────┘                       │
│                    │                                   │
│                    ▼                                   │
│            track_angle (航向角)                        │
│                    │                                   │
│                    ▼                                   │
│         ┌─────────────────────┐                       │
│         │ 角度环 (PD)          │ ← 航向角微调           │
│         │ Kp=4, Kd=8, Ki=0    │                       │
│         └─────────────────────┘                       │
│                    │                                   │
│                    ▼                                   │
│          总转向 = 转向环 + 角度环                      │
│                    │                                   │
│                    ▼                                   │
│         ┌─────────────────────┐                       │
│         │ 速度环 (PI)          │ ← 控制左右轮速度差     │
│         │ Kp=?, Ki=?, Kd=0    │                       │
│         └─────────────────────┘                       │
│                    │                                   │
│                    ▼                                   │
│            my_motor_set_speed()                        │
│                                                         │
└─────────────────────────────────────────────────────────┘
```

### 1.2 各环作用与调参原则

| 控制器 | 输入 | 输出 | 控制类型 | 调参目标 | 为何用/不用 Ki |
|--------|------|------|----------|----------|----------------|
| **转向环** | `track_error` (像素) | 转向输出 | **PD** | 快速响应横向偏差，抑制振荡 | Ki会导致过调振荡，位置误差无需积分 |
| **角度环** | `track_angle` (弧度) | 航向修正 | **PD** | 快速对准赛道方向，抑制车头甩动 | 角度无稳态误差，积分无物理意义 |
| **速度环** | `目标速度-实际速度` | 油门输出 | **PI** | 精确跟踪速度设定，消除静差 | Ki消除速度静差，保证最终速度准确 |

### 1.3 逐飞助手在线调参通道映射

逐飞助手的"在线调参"功能让 PC 端拖滑块实时修改参数，无需重新编译烧录。

**支持**: 点击逐飞助手"开启调参"，拖滑块即可生效。

| 通道 | 代码变量 | 初始值 | 说明 |
|:----:|---------|:------:|------|
| 0 | `g_steer_kp` | 5 | 直道转向 Kp |
| 1 | `g_steer_kd` | 11 | 直道转向 Kd |
| 2 | `g_steer_kp_curve` | 10 | 弯道转向 Kp (钝角弯+直角弯共用) |
| 3 | `g_steer_kd_curve` | 13 | 弯道转向 Kd (钝角弯+直角弯共用) |
| 4 | `g_speed_kp` | 30 | 速度环 Kp |
| 5 | `g_speed_ki` | 2 | 速度环 Ki |
| 6 | `g_angle_kp` | 4 | 角度环 Kp |
| 7 | `g_angle_kd` | 8 | 角度环 Kd |

> **注意**: 弯道参数 (ch2/ch3) 同时影响钝角弯和直角弯，简化调参。
> 调完后记得把最终值回填到 `pid_controller.h` 的宏定义里，下次编译就是默认值。

### 1.4 虚拟示波器通道映射 (车→PC 看波形)

虚拟示波器通过 WiFi SPI 实时发送运行数据到逐飞助手，用于观察控制效果。

| 通道 | 变量 | 物理含义 | 调参时看什么 |
|:----:|------|---------|-------------|
| ch0 | `steer_error` | 横向偏差 (像素) | 直道是否画龙、弯道偏差峰值 |
| ch1 | `steer_output` | 位置环 PD 输出 | 横向修正是否平滑 |
| ch2 | `angle_error` | 航向偏差 (像素/10行) | 车头指向与赛道方向差多少 |
| ch3 | `angle_output` | 角度环 PD 输出 | 航向修正是否合理 |
| ch4 | `total_steer` | 合并转向 (ch1+ch3) | 总转向量、是否过冲/饱和 |
| ch5 | `avg_speed` | 实际速度 (编码器) | 速度跟随情况 |
| ch6 | `target_speed` | 目标速度 | 和 ch5 叠看响应速度 |
| ch7 | `speed_output` | 速度 PI 输出 | 速度环是否饱和 |

### 1.5 完整调参工作流

```
逐飞助手 PC端
  │
  ├─ 图传: 看二值化图像 + 赛道边界线
  │     → 判断巡线是否正确、元素检测是否误判
  │
  ├─ 虚拟示波器 (车→PC): 看 8 通道波形
  │     ch0: track_error     ch1: steer_output
  │     ch2: angle_error     ch3: angle_output
  │     ch4: total_steer     ch5: avg_speed
  │     ch6: target_speed    ch7: speed_output
  │     → 诊断: 振荡? 过冲? 响应慢? 速度跟不上?
  │
  └─ 在线调参 (PC→车): 拖滑块实时改参数
        ch0: 直道转向Kp    ch1: 直道转向Kd
        ch2: 弯道转向Kp    ch3: 弯道转向Kd
        ch4: 速度环Kp      ch5: 速度环Ki
        ch6: 角度环Kp      ch7: 角度环Kd
        → 根据波形诊断结果, 拖滑块改参数, 立即看效果

调参流程:
  ① 跑一圈 → 看示波器波形 → 诊断问题
  ② 拖在线调参滑块改参数 → 再跑 → 看波形变化
  ③ 反复迭代 → 找到最佳值 → 回填到 pid_controller.h

### 调参原则

- **Kp 增大**: 响应更快，但过大导致振荡
- **Kd 增大**: 阻尼更强，减少振荡，但过大导致响应迟钝

- **直角弯**: Kp 最大，Kd 最大，确保90度转弯

## 七、逐飞助手在线调参流程

### 7.1 连接设置
1. 确保 WiFi 模块 IP 正确（TCP Server 端口 8086）
2. 点击「开启调参」按钮
3. 设置 8 个通道初始值（见1.3节）

### 7.2 调参顺序建议
```
1. 直道转向 Kp/Kd (通道0/1)
   - 先调 Kp: 从小到大，直到车开始轻微振荡
   - 再调 Kd: 从0开始增加，直到振荡消失
   
2. 速度环 Kp/Ki (通道4/5)
   - 先调 Kp: 让速度能跟上设定值
   - 再调 Ki: 消除速度静差
   
3. 角度环 Kp/Kd (通道6/7)
   - 调 Kp: 车头快速对准赛道方向
   - 调 Kd: 抑制车头摆动
   
4. 弯道转向 Kp/Kd (通道2/3)
   - 在弯道场景下微调，比直道稍大
```

### 7.3 示波器监控关键信号
| 通道 | 信号 | 正常表现 |
|------|------|----------|
| ch0 | track_error | 直道时在0附近小幅度波动 |
| ch1 | steer_output | 与track_error反相，无剧烈跳变 |
| ch2 | track_angle | 弯道时平滑变化，直道时接近0 |
| ch3 | left_speed | 与目标速度基本一致 |
| ch4 | speed_pid.output | 输出平稳，无剧烈振荡 |
